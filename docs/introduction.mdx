## Overview

This project is a lightweight, scalable engine designed to handle real-time data streaming using **Server-Sent Events (SSE)**. It leverages **Redis Pub/Sub** to allow stateless Go instances to broadcast messages across a distributed system.

## Key Features

* **Stateless Architecture**: Any server instance can handle any client.
* **SSE Streaming**: Native browser support without heavy WebSocket overhead.
* **ACK Mechanism**: (Optional) Ensures message delivery reliability.
* **Docker Ready**: Easily deployable via containers.
