## Overview

Clears all pending messages from a user's Inbox in Redis. Call this after the client has successfully received and processed all messages.

<Note>
The current implementation clears the ENTIRE inbox. For individual message acknowledgment, you would need to modify the ClearInbox function to accept a message ID.
</Note>

## Endpoint
POST /ack

## Request Body

<ParamField body="user_id" type="string" required>
  User's unique identifier whose inbox should be cleared
</ParamField>

## Response
acknowledged

## Behavior

### What Happens

The server executes a Lua script atomically:
```lua
local msgs = redis.call('LRANGE', KEYS[1], 0, -1)
redis.call('DEL', KEYS[1])
return msgs
```

This:
1. Retrieves all messages from `inbox:user_id`
2. Deletes the entire list
3. Returns the messages (for potential future use)

### Why It Matters

Without acknowledgment:
- Inbox never clears
- Client receives duplicates on every reconnect
- Redis memory usage grows unbounded

<Warning>
Always call `/ack` after successfully processing messages to prevent memory leaks and duplicate delivery.
</Warning>

## Implementation Details

From the source code:
```go
func (b *RedisBroker) ClearInbox(ctx context.Context, userID string) ([][]byte, error) {
    key := "inbox:" + userID

    script := redis.NewScript(`
        local msgs = redis.call('LRANGE', KEYS[1], 0, -1)
        redis.call('DEL', KEYS[1])
        return msgs
    `)

    result, err := script.Run(ctx, b.Client, []string{key}).Result()
    // ... conversion logic
}
```

<Tip>
For production use cases requiring individual message acknowledgment, modify this to accept a message ID and use `LREM` instead of `DEL`.
</Tip>

## Best Practices

### Acknowledge After Display
```javascript
const processedMessages = new Set();

eventSource.onmessage = async (event) => {
  const message = JSON.parse(event.data);
  
  // Only acknowledge after successfully displaying
  try {
    await displayNotification(message.payload);
    processedMessages.add(message);
    
    // Acknowledge only after all messages processed
    if (allMessagesReceived()) {
      await fetch('/ack', {
        method: 'POST',
        body: JSON.stringify({ user_id: userId })
      });
    }
  } catch (error) {
    console.error('Failed to process message:', error);
    // Don't acknowledge if processing failed
  }
};
```

### Handle Network Failures
```javascript
async function acknowledgeWithRetry(userId, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      await fetch('/ack', {
        method: 'POST',
        body: JSON.stringify({ user_id: userId })
      });
      return; // Success
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      await new Promise(resolve => setTimeout(resolve, 1000 * Math.pow(2, i)));
    }
  }
}
```
