## Overview

Opens a persistent Server-Sent Events (SSE) stream for real-time message delivery. Automatically flushes pending messages from the user's Inbox queue before starting the live stream.

---

## Endpoint Configuration

### 1. Production Mode (JWT Authentication)
In production, clients must connect using a JWT signed by your main backend:

```http
GET /connect?token={signed_jwt}
```

#### JWT Claims Schema
The JWT signature is validated using `JWT_SECRET` and must contain:
* `sub` (or `user_id`): The client's unique user identifier.
* `channels`: An array of strings representing the channels this client is authorized to subscribe to.

### 2. Development Mode (Zero-Config)
For development purposes (when `JWT_SECRET` is not set), you can pass credentials in the query parameters:

```http
GET /connect?id={client_id}&channels=general,room_A
```

*By default, all connections join the `general` channel.*

---

## Response Header
* **Content-Type:** `text/event-stream`
* **Cache-Control:** `no-cache`
* **Connection:** `keep-alive`
* **X-Accel-Buffering:** `no` (Disables Nginx buffering)

## Client Examples

<CodeGroup>
```javascript JavaScript (Browser)
// Connection query in Development Mode
const userId = 'user_123';
const eventSource = new EventSource(`http://localhost/connect?id=${userId}&channels=general,room_A`);

eventSource.onopen = async () => {
  console.log('Connected to real-time engine');
  
  // Acknowledge connection to clear offline inbox
  await fetch('http://localhost/ack', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ user_id: userId })
  });
};

eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  const payload = data.Payload || data.payload;
  console.log('Received:', payload);
};
```

```python Python
import sseclient
import requests

def listen_to_messages(user_id):
    # Establish connection
    response = requests.get(
        f'http://localhost/connect?id={user_id}&channels=general',
        stream=True,
        headers={'Accept': 'text/event-stream'}
    )
    
    client = sseclient.SSEClient(response)
    
    # Acknowledge connection
    requests.post('http://localhost/ack', json={'user_id': user_id})
    
    for event in client.events():
        message = json.loads(event.data)
        print(f"Received: {message['payload']}")
```

## System Behavior

### On Connection Handshake
1. The gateway extracts the client identity and channel permissions (via query params or JWT verification).
2. The gateway retrieves and flushes all pending messages from `inbox:{client_id}` in Redis immediately.
3. The gateway registers the connection locally inside its active clients map.
4. The client receives live updates published to any of its subscribed channels.

### During Connection
* A heartbeat ping (`: keepalive`) is sent every 15 seconds to prevent load balancer timeouts.
* Browser clients automatically reconnect if the connection drops.

### On Disconnection
* The node removes the client from its local registry.
* Targeted messages (`to_user`) sent to offline clients continue to accumulate in their Redis inbox.
