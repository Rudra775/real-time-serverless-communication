description: 'Publish a message to a channel and queue for offline users'

## Overview

Publishes a message to a specific channel. If targeted user IDs are specified, the message is also saved to their inboxes in Redis for reliable delivery.

---

## Endpoint Configuration

* **URL:** `/send`
* **Method:** `POST`
* **Headers:** `X-API-Key: {your_secret_key}` (Required if `REALTIME_API_KEY` is configured)

---

## Request Body Fields

<ParamField body="channel" type="string">
  The target channel (e.g. `room_A`). If omitted, defaults to `general`.
</ParamField>

<ParamField body="to_user" type="string">
  Single target user ID. If provided, the message is saved in `inbox:{user_id}` for reliable delivery.
</ParamField>

<ParamField body="to_users" type="array">
  Array of target user ID strings. The message is cloned and saved to each user's inbox list.
</ParamField>

<ParamField body="data" type="object" required>
  The message payload that will be delivered to connected clients.
</ParamField>

---

## Examples

<CodeGroup>
```bash cURL
curl -X POST http://localhost/send \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your_secret_key" \
  -d '{
    "channel": "orders_feed",
    "to_user": "user_123",
    "data": {
      "type": "notification",
      "title": "Order Shipped",
      "message": "Your package is on its way!"
    }
  }'
```

```python Python
import requests
import os

api_key = os.getenv("REALTIME_API_KEY")

response = requests.post(
    'http://localhost/send',
    headers={'X-API-Key': api_key},
    json={
        'channel': 'announcements',
        'data': {
            'type': 'broadcast',
            'message': 'System maintenance scheduled for tonight.'
        }
    }
)
```
</CodeGroup>
